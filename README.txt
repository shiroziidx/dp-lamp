DP Lamp Manager / iPhone PWA
全ファイルを同じHTTPSサイトのフォルダに配置（GitHub Pages等）。Safariでindex.htmlを開き、共有→ホーム画面に追加。ホーム画面のアイコンからオンラインで初回起動し、オフライン準備済を確認してから機内モードで再起動テスト。CSVは端末内IndexedDBに保存。定期的に設定からバックアップを保存してください。
seed.jsは空の初期データです。インストール後に元のCSVを取り込んでください。
難易度CSV形式: タイトル,譜面,ノマゲ,ハード。数値未登録は空欄。非公式難易度の実データは未同梱。公式CSVリンクは33のページを初期値とし設定で変更可能。履歴は取込日基準。DP/SPの判別は公式CSVの列だけではできないためDPを選択してください。
